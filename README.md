# Player Value Prediction Project

This project focuses on using machine learning to predict the market value of football players based on their characteristics and performance statistics. The dataset contains information about players, including attributes such as age, position, performance metrics, and other player-related features.

The project follows a complete machine learning workflow, including data cleaning, handling missing values, exploratory data analysis (EDA), preprocessing categorical and numerical variables, and feature preparation.

Two regression models are used to predict player market value:

* **Linear Regression** – used as a baseline model to understand the relationship between player attributes and market value.
* **Random Forest Regression** – used to capture more complex and non-linear relationships between player characteristics and their market value.

The models are evaluated using **Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² score**. The results are compared to assess how effectively the models can predict player market values.

The overall goal is to demonstrate how machine learning can be applied to sports data to estimate player market values from available player characteristics and performance information.
